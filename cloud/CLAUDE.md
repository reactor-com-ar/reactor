# cloud

El archivo [DESIGN.md](DESIGN.md) es el referente para todo el diseño de esta aplicación llamada "cloud". Consultarlo antes de proponer cambios de arquitectura, decisiones de diseño o nuevas funcionalidades.

El archivo [STACK.md](STACK.md) se debe usar como plantilla para el stack técnico y la arquitectura de la aplicación. Consultarlo antes de proponer cambios en tecnologías, estructura de carpetas, convenciones de código o flujo de deploy.

El archivo [ABM.md](ABM.md) define las convenciones obligatorias para todo módulo ABM (Alta, Baja, Modificación) del sistema: orden de columnas del listado, estructura del buscador, modales de Consultar/Alta/Edición y reglas visuales asociadas. Consultarlo y respetarlo siempre que se cree o modifique un ABM, salvo indicación contraria explícita.
